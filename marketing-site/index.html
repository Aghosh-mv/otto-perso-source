Features

Not a chatbot.
An agent that acts.

Chat is the home

Not a dashboard. Not a control panel. You talk to Otto like a colleague. It does the rest.

Spawns its own brains

Complex request? Otto decomposes it and spawns new Otto brains — each a complete instance with tools, memory, and focus.

Real memory

Obsidian-compatible vault on disk. Otto remembers what matters. Edit it alongside Otto. Changes sync both ways.

5-tier autonomy

From "ask before editing" to "vacation mode". You decide how much freedom Otto has. Emergency stop always one tap away.

26 real tools

Reads files, searches the web, writes notes, creates tasks, sends SMS and email. Not a chatbot — an agent that acts.

Yours, locally

Everything stays on your device. No cloud, no telemetry, no subscription. MIT licensed. Inspect every line.

# or
